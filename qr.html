Make a QR code for your calendar

Calendar addresses are long and easy to mistype on a tablet. Paste yours below, then scan the code with RoomBoard instead of typing it.

Your calendar address

Your QR code will appear here.

Then, on the tablet

  1. Open RoomBoard and go to the calendar step in setup, or Settings → Calendar.
  2. Tap Scan QR.
  3. Point the camera at this screen.
  4. Tap Test connection to confirm it works before mounting the tablet.
Nothing is uploaded. The code is generated by this page in your own browser. Your calendar address is never sent to us or to anyone else - which matters, because that address is effectively a password to your calendar.

Where to find the address

  1. Google Calendar: Settings and sharing → Integrate calendar → “Secret address in iCal format”.
  2. Outlook / Microsoft 365: Settings → Calendar → Shared calendars → Publish a calendar → “Can view all details” → copy the ICS link.
  3. Apple Calendar: Right-click the calendar → Share Calendar → tick Public Calendar → copy the link.
