# snowbyteapps.github.io

Public site for Snowbyte apps, served by GitHub Pages at
<https://snowbyteapps.github.io>.

Deliberately separate from the app source, which stays private: GitHub Pages
cannot serve from a private repo on a free account, and the privacy policy URL
has to be publicly reachable for the Play Store listing.

| File | Serves |
|---|---|
| `index.html` | Landing page |
| `privacy.html` | Privacy policy — this URL goes in the Play listing |

The privacy policy URL must not change after a store submission: a dead link
during review is a rejection risk.
